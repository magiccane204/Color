# 🎨 ChromaCognitive: An Empirical Study in Chromatic Dissonance

## 💡 Why This Exists (The Justification)
Most modern design systems are depressingly predictable. `Primary color` always means a primary color; `Indigo` always matches indigo. **ChromaCognitive** was built as a high-concept front-end experiment designed to push the boundaries of user trust, visual hierarchy, and sensory adaptation.

By exploring dynamic CSS features learned during early-stage web development, this application serves as a rigorous cognitive stress-test for users—challenging whether they are paying attention to visual labels or blindly clicking "Click me".

---

## ✨ Key Features & Technical Highlights

* **Dynamic Reactive Backgrounds:** Selecting a color card aggressively engulfs the entire viewport layout in that exact aesthetic, forcing the user to visually experience their selection.
* **The Stroop Effect Module:** Explores visual-semantic dissonance by cross-contaminating color swatches and labels (such as mapping the **Indigo** label to a purple token and vice versa) to test cognitive processing speed.
* **Zero-Dependency Core:** Built purely with raw HTML & CSS to master native styling fundamentals without framework bloat or external dependencies.
* **Granular Micro-Interactions:** Custom hover states, subtle card dropshadows, and responsive grid layouts designed to test element spacing and layout bounds.

---

## 🛠 Tech Stack

* **HTML5:** Semantic structure and content architecture.
* **CSS3:** Custom card layouts, CSS grid/flexbox, box-shadows, dynamic color overrides, and hover transformations.
